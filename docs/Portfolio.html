Description

The auto_claim data set comes from the SOA’s Predictive Analytics Exam practice materials, it contains 10296 observations and 29 variables. This data was collected in order to promote predictive analytics education within an actuarial context. Each observation is an individual auto insurance policy. Some of the variables include demographic information of the policy holder such as age, gender, income, and education. Other variables include characteristics about the vehicle such as car type, blue book value, and car use. The response variable that is being investigated in this analysis will be the CLM_FLAG variable which indicates whether or not a policy has made a claim. About 27% of policies have a claim, while 73% do not. We will be exploring which policy holder and vehicle characteristics are associated with a higher likelihood of filing a claim.

Before splitting the data, missing values in INCOME, HOME_VAL, YOJ, and SAMEHOME were imputed using median imputation, preserving all 10296 observations. The data was then split in to a training set(80%, n = 8236) and a test set(20%, n = 2060). A stratified sample was used to ensure that the ratio of policies with claims vs policies with no claims were roughly equal between the two sets. The size of the each set is appropriate since there is ample data to train the models with while keeping enough data left over to test on.

Section 3: Unsupervised Learning

Principal Component Analysis is a technique that aims to reduce the dimensionality of a large set of correlated variables in to a smaller set of uncorrelated variables called principal components. Each component is a linear combination of the original variables constructed in such a way that captures as much variation in the data as possible. The first component explains the most variation, the second component explains the second most variance, and so on. In this analysis, PCA was performed on 9 numeric variables from the set: AGE, INCOME, HOME_VAL, BLUEBOOK, TRAVTIME, MVR_PTS, NPOLICY, HOMEKIDS, and KIDSDRIV. All variables were standardized to ensure they contribute equally to the analysis.

Section 4: Supervised Learning

Two Classification models were used to predict whether a policyholder would file a claim. The first model was a logistic regression model with lasso regularization and the second model was a random forest. 5-fold cross validation was used to tune the hyperparameters.

### convert character variables to factors

test <- test |> mutate(across(all_of(factors), as.factor))

  step_dummy(all_nominal_predictors()) |>

Logistic regression is extension linear regression, however it is used to predict binary outcomes rather than numeric values. In this case, it predicts the probability of policyholder falling in to one of two classes, that being whether a claim was filed or not. If the predicted probability of filing a claim exceeds 50%, then the policyholder is classified as Yes, if not, they are classified as No.

Lasso regularization was used to automatically penalize unimportant predictors in the model. This method simplifies the model while also preventing over fitting on the training data. The penalty in this case is referred to as ‘lambda’. The higher lambda is, the higher the penalization is on the predictor variables, which results in a simpler model that may miss more patterns(more bias). A lower lambda fits the model more closely to the training data, but could result in over fitting(more variance). Higher variance means the model is more sensitive to changes in the training data, which could lead to model making poor predictions when presented with new data.The optimal lambda selected was 0.00234, this is a relatively small value which indicates that most of the predictors were useful.

The logistic regression achieved a mean cross validation accuracy of 78.5% (std error: 0.23%) and a test set accuracy of 79.1% #### Random Forest

In a random forest model, many decision trees are trained on a slightly different random sample(with replacement) of the data. At every split in a tree, it only considers a subset of predictors rather than all of them. Each tree then makes a prediction on a new data point. The prediction that receives the most ‘votes’ becomes the final prediction.

The Random Forest achieved a mean cross validation accuracy of 78.3% (std error: 0.27%) and a test set accuracy of 78.1%

Both models performed similarly, suggesting a straightforward relationship between claim status and the predictors. Additionally, the fact that the mean cross-validation accuracy and test accuracy were very close for both models suggests that neither model is over fitting the training data.
